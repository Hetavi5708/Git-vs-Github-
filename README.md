# Git & GitHub Workshop — Demo Website

Welcome to the live demo website for the SCET Git & GitHub Workshop!

## Project Overview
This is a starter web project designed to teach beginners how to:
- Fork and clone repositories.
- Create feature branches (`git checkout -b`).
- Stage and commit code (`git add` and `git commit`).
- Push branches and open Pull Requests (PRs) on GitHub.

## Files
- `index.html` — Homepage
- `about.html` — About Us & Workshop Leads
- `contact.html` — Contact Information
- `style.css` — Main Stylesheet
